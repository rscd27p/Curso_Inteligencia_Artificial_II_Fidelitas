# Curso_Inteligencia_Artificial_II_Fidelitas
Repositorio oficial del curso CD-701 Inteligencia Artificial II enfocado en aprendizaje práctico mediante Jupyter Notebooks y Google Colab. Incluye laboratorios de NLP, LLMs, embeddings, RAG, transformers, búsqueda semántica y aplicaciones modernas de IA generativa orientadas a ingeniería de IA.
